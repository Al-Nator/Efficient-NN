# Efficient NN

hw1/ - аналитическая модель производительности CNN, измерения и отчёт.
hw2/ - воспроизведение Selection via Proxy, отчёт и презентация.

Для обоих ДЗ нужны Python 3.12, uv и NVIDIA GPU с драйвером для CUDA 12.8.
У каждого ДЗ отдельное окружение. Команды запуска приведены в hw1/README.md и hw2/README.md.
